# **RETAIL BILLING SYSTEM – PROJECT REPORT**

## 1. Introduction

This project is a Retail Billing and Inventory Management System based on Python. It enables a store to manage items, track inventory, create customer bills and see sales reports. The system is simple, interactive and provides a clean menu driven interface.

---

## 2. Project Objectives

Maintain a reliable inventory of items.

Create bills with accurate item-wise calculations

Automatically deduct stock after each sale

Maintain and display total sales of the day.

Produce an easy, visually appealing and user-friendly output for business use.

---

## 3. System Features

   

• Add Item to Inventory

Allows the user to input:

Item name

Item price

Stock / Quantity available.

These item inputs are stored in a dictionary for rapid access.




• See Inventory

Displays:


Item name

Price

Available stock

The user can use this feature to assist in providing an up-to-date view of their current store inventory.





• Create a Bill

Allows the user to:

Input multiple items

Choose quantity.

This will compute automatically the item-wise price, and total.

The bill will display:
 
An item, 

The quantity 

The price

The line total

Final bill




• Automatic Stock Reduction

Once the item(s) and quantity have been submitted for billing, the stock is then automatically reduced.


stock = stock - quantity


This assists in keeping an updated inventory.




• Sales Report

Displays:
 
All billed items

Bill number

Total amount.
